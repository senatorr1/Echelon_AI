# Echelon_AI

AI-powered cybersecurity and business consultant built with Python and Streamlit.

## Features

- **Cybersecurity Consultation**: Get expert advice on online safety and digital protection
- **Income Generation Advisory**: Personalized business and service recommendations for students
- **Security Tools**: Password checker, phishing analyzer, URL safety scanner
- **Dark Mode**: Toggle between light and dark themes
- **Chat History**: Save and export conversations

## Technologies

- Python 3.11
- Streamlit
- Groq AI API
- VirusTotal API
